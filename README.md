# My Portfolio

## Overview
Welcome to my portfolio! This showcases my work as a **frontend-focused full-stack developer**, highlighting my expertise in **Angular, animations, and UI/UX development**. The portfolio is built using **Angular** and deployed via **Netlify** for seamless accessibility.

## Features
- **Dynamic UI**: Smooth animations and transitions for an engaging user experience.
- **Responsive Design**: Fully optimized for desktop and mobile viewing.
- **Project Showcase**: Highlights my key projects with detailed descriptions and live demos.
- **Contact Form**: Allows visitors to reach out directly.
- **Fast Performance**: Optimized for quick load times and smooth interactions.

## Technology Stack
- **Frontend**: Angular (for building the UI)
- **Animations**: Angular Animations for smooth transitions
- **Deployment**: Hosted on Netlify for fast and secure access
